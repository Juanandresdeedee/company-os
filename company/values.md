# Values

## Draft

List values that should shape behavior and decisions.

## Value standard

Each value should create a real tradeoff. If it never changes a decision, it is not a value.

## Operating principles

List the action rules that follow from the values.

Each principle should guide daily judgment.

## Prompts

- What behavior do we reward even when it is inconvenient?
- What behavior do we reject even when it is profitable?
- What principles should agents preserve when optimizing?
- When speed and quality conflict, what wins?
- When customer requests and strategy conflict, what wins?
