# Wiki

`wiki/` contains durable reference docs: SOPs, playbooks, onboarding, recurring process notes, and reusable operating knowledge.

## What belongs here

- SOPs and playbooks
- onboarding materials
- reference docs
- recurring process explanations
- reusable examples that have been reviewed

## What does not belong here

- generated drafts
- unprocessed raw notes
- live project task lists
- strategy decisions without decision records

## Recommended files

- `onboarding.md`
- `playbooks.md`
- `sops.md`
- `communication.md`
- `process-reference.md`

## Prompts for operators

- What do new people ask repeatedly?
- What work should be repeatable without tribal knowledge?
- What should agents know before executing this workflow?
- Which repeated SOP should become a managed skill?
