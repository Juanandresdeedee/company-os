# Managed skills

`.ai/skills/` contains Company OS managed starter skills. Future CLI tooling may use this directory as the managed source for installing, updating, or validating skills.

Use `SKILLS.md` for local installation and update instructions.

## What belongs here

- blueprint-owned `SKILL.md` folders
- references used by those skills
- examples and quality checklists for managed skills

## What does not belong here

- one-off personal prompts
- generated drafts
- private client material
- unmanaged local experiments

## Current skills

| Skill | purpose |
| --- | --- |
| `board-of-directors` | Board-style review for high-stakes founder/operator decisions, strategy, finance, risk, governance, customer, and operations tradeoffs. |
| `company-purpose` | Guided interview for purpose, vision, values, principles, strategic ambition, and a 12-36 month goal. |
