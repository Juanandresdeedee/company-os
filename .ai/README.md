# AI

`.ai/` contains Company OS managed AI assets. These files are part of the blueprint and may be discovered by future installer or updater tooling. See `SKILLS.md` for local installation instructions.

## What belongs here

- managed starter skills
- AI asset metadata
- blueprint-owned agent resources

## What does not belong here

- local personal prompts
- tool secrets
- generated output
- third-party runtime code
