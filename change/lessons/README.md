# Lessons

`change/lessons/` contains project reflections and harvest candidates. Each lesson should link directly to the project section in [projects.md](/change/projects.md) and to the reflection file that explains the context.

## Lesson index

| Lesson | project | reflection | suggested destination | owner | status |
| --- | --- | --- | --- | --- | --- |

## Reflection standard

Create one reflection file per project review, retro, or meaningful learning event.

Name reflection files with the date and project slug:

```text
YYYYMMDD-project-slug-reflection.md
```

Each reflection should include:

- a direct link to the project section in [projects.md](/change/projects.md)
- the situation or milestone that produced the lesson
- what worked
- what did not work
- what should change in a run process, playbook, skill, or decision
- whether the learning is general enough to harvest

## Harvest prompts

- Does this learning generalize beyond one project?
- Should it update a recurring process in `run/`?
- Should it become a playbook in `wiki/`?
- Should it become a managed skill or agent instruction?
- Should it become a durable decision in `decisions/`?
